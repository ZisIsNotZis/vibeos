# VibeOS logo generation prompt

Create a distinctive vector logo for **VibeOS**, an operating system whose desktop world is authored on demand by an AI coding agent. The mark should communicate a living, expandable world and a trustworthy real operating system: a clean geometric window or portal containing a subtle branching-world/tree motif, with one elegant spark of motion or emergence. Use a dark graphite base with electric violet and cyan accents, high contrast, premium modern software identity, calm and precise rather than playful. Make it recognizable at 16px and compelling at app-icon size. Produce a flat vector-style symbol plus a wordmark reading “VibeOS”, with a transparent background. No gradients that disappear at small sizes, no mockup, no device frame, no 3D render, no extra text, no mascots, no cliché brain/robot imagery. Deliver SVG and a square transparent PNG variant.
